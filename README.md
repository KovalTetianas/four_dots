# Четыре точки — иконка, которой управляют удалённо

Иконка в Chrome: 4 точки квадратом. Любую точку можно сделать «жирной» (крупнее), всего 16 вариантов.
Другой человек в своём браузере открывает страницу-пульт, выбирает вариант, и иконка у тебя меняется сразу.

```
[пульт в чужом браузере] --POST--> [сервер] --WebSocket--> [расширение у тебя] --> иконка
```

## Состав
- `extension/` — расширение Chrome (Manifest V3), иконки в `extension/icons/`
- `server/` — сервер на Node.js и страница-пульт (`server/public/index.html`)
- `generate_icons.py` — заново рисует все иконки (`python3 generate_icons.py`, нужен Pillow)
- `preview_all_variants.png` — все 16 вариантов на одном листе

Код варианта — 4 цифры в порядке «верх-лево, верх-право, низ-лево, низ-право», 1 = жирная точка.
Например, `1001` — жирные точки верх-лево и низ-право. Файлы: `icons/dots_1001_16.png` и т.д.

## Запуск
1. Сервер:
   ```bash
   cd server && npm install && npm start
   ```
   Поднимется на `http://localhost:8787` (порт задаётся переменной `PORT`).
   Для работы через интернет сервер выкладывается на Render: Web Service, Root Directory `server`,
   Build Command `npm install`, Start Command `npm start`, тариф Free.
2. Расширение: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `extension`.
3. Нажми на иконку расширения: впиши адрес сервера и нажми OK. Скопируй «Ссылку на пульт» и отправь её другому человеку.

## API
- `GET  /api/state/<room>` → `{"state":"1010"}`
- `POST /api/state/<room>` с телом `{"state":"1010"}`
- `WS   /ws?room=<room>` — сразу присылает текущее состояние, дальше все изменения
